# Evidence folder

Save test evidence here using the names in `tests/test-plan.md`:

- `T01-topology.png`
- `T02-show-vlan-sw1.png`
- `T05-auth-session-staff1.txt`
- `T09-wrong-password.txt`
- `T17-access-lists.txt`
- and so on.

Use `.png` for screenshots and `.txt` for copied console output. Keep the
original command line at the top of each text file so the result can be
reproduced. The report outline's appendix C indexes these files.
